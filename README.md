# Modelos anatômicos BodyParts3D

Os arquivos STL desta pasta são derivados do **BodyParts3D / Anatomography**, versão 3.0, mantido pelo Database Center for Life Science (DBCLS), Japão.

Licença do conteúdo: Creative Commons Attribution-ShareAlike 2.1 Japan (CC BY-SA 2.1 JP).

Atribuição exigida: `BodyParts3D, © The Database Center for Life Science, licensed under CC Attribution-Share Alike 2.1 Japan.`

Fonte e documentação: https://github.com/BodyParts3D/BodyParts3D

Publicação científica: Mitsuhashi N. et al. “BodyParts3D: 3D structure database for anatomical concepts.” Nucleic Acids Research. 2009;37:D782–D785. DOI: 10.1093/nar/gkn613.

Aviso: recurso educacional. Não deve ser usado para diagnóstico, planejamento cirúrgico ou substituição de atlas e supervisão profissional validados.
